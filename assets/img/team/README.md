# Team photos

Drop member photos here (square works best — they are shown as small round
avatars, ~48px). Name them simply, e.g. `remi-flamary.jpg`, then reference them
in `_data/team.yml`:

```yaml
- name: "Rémi Flamary"
  link: "https://remi.flamary.com/"
  photo: "/assets/img/team/remi-flamary.jpg"
```

Without a `photo:`, the site shows a monogram (the person's initials) instead.
