# Team photos

Drop member photos here (square works best — they are shown as small round
avatars, ~48px). Then reference them in `_data/team.yml` with **just the file
name** (the site adds the `assets/img/team/` path for you):

```yaml
- name: "Rémi Flamary"
  link: "https://remi.flamary.com/"
  photo: "remi.jpg"        # the file assets/img/team/remi.jpg
```

A full path (e.g. `/assets/img/team/remi.jpg`) also works. Without a `photo:`,
the site shows a monogram (the person's initials) instead.
